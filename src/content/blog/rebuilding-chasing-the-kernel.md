ポートフォリオ、学習用 Wiki、技術 Blog を一つの場所にまとめるため、サイトをゼロから作り直すことにしました。

最初の構成は Astro と Cloudflare Workers を採用し、コンテンツは Git で管理します。まずは小さな骨格から始め、必要な機能を少しずつ追加していきます。
